A simple library to allow for brstm files to be used in Media Chrome, based on [Revolving Door](https://github.com/rphsoftware/revolving-door).

# Usage:
```
<media-controller audio>
    <brstm-audio
      slot="media"
      src="./song.brstm"
      preload="auto">
    </brstm-audio>

    <media-control-bar>
      <media-play-button></media-play-button>
      <media-time-display></media-time-display>
      <media-time-range></media-time-range>
      <media-duration-display></media-duration-display>
      <media-mute-button></media-mute-button>
      <media-volume-range></media-volume-range>
    </media-control-bar>
  </media-controller>

```
